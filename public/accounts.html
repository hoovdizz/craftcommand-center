Common Minecraft server properties

Most server-property adjustments fall into three categories. These values are edited in the container's server.properties file and generally require a server restart.

Performance optimization

view-distance, tick-distance, max-threads, and player-idle-timeout balance simulation range, CPU use, and memory.

Security

allow-list, online-mode, texturepack-required, and allow-cheats control who can join and which server privileges are enabled.

Core gameplay

gamemode, difficulty, force-gamemode, and default-player-permission-level define the default player experience.

Access levels

Viewer

Can view status, known players, kits, the item catalog, and only their own activity. Cannot send commands.

Operator

Can send item, XP, and kit commands, refresh player/attachment data, and view only their own activity.

Admin

Can also manage accounts, manually save players, create/delete kits, and clear activity.

Accounts

The primary admin is controlled by the Unraid template. Additional accounts are saved in /app/data/users.json.
